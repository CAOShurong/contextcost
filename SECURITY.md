# Security policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

<https://github.com/CAOShurong/contextcost/security/advisories/new>

Do not open a public issue for a vulnerability that could expose another
person's files, credentials, repository contents, or build pipeline. Include a
minimal reproduction, affected version, operating system, and the boundary you
expected ContextCost to enforce. Reports about ordinary classification quality
or documentation can use the public issue tracker.

No response-time guarantee is claimed. A report will be acknowledged when the
maintainer has actually reviewed it; release notes will describe verified
impact without inventing affected users.
